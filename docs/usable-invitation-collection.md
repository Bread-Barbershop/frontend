# 홈 카드 표지에서 시작하는 편집 템플릿

홈의 25개 카드 표지를 템플릿 선택 화면과 제작 시작 화면에서도 같은 원본 썸네일로 보여 줍니다. 편집기를 열면 선택한 원본 Fabric JSON 한 개만 가져와 표지의 글자, 사진 프레임, 선, 도형과 폰트 스타일을 편집 가능한 객체로 불러옵니다. 전체 표지를 배경 이미지 한 장으로 고정하지 않습니다.

## 표지 편집 범위

원본 JSON을 선택한 시점에만 가져옵니다. 불러온 표지의 텍스트와 글자별 스타일, 사진 프레임, 도형 및 이미지 패턴을 보존하고 새 문서마다 편집 오브젝트 ID와 교체 슬롯 ID를 새로 부여합니다. `background-layer` ID처럼 에디터 동작에 의미가 있는 ID는 유지합니다. 원본 폰트 목록은 템플릿 선택 화면에 표시하며 캔버스는 기존 폰트 준비와 로드 후 안정화 절차를 사용합니다.

홈 카드와 썸네일은 완성된 원본 표지를 보여 줍니다. 다만 편집용 JSON의 사진 영역 일부는 실제 사진 데이터 대신 카메라 안내 패턴과 비어 있는 교체 슬롯으로 저장되어 있습니다. 원본 이미지 자산에 사진 원본은 포함되어 있지 않으므로 편집 화면에서는 해당 프레임에 사진을 넣어 마무리합니다. 사진이 들어간 썸네일 자체를 캔버스 배경으로 사용하지 않습니다.

원본 파일을 불러오지 못하거나 응답이 제한 시간 안에 끝나지 않으면 편집기와 기존 문서는 적용 전 상태로 유지되고 다시 시도할 수 있습니다. 글자와 프레임을 한 장의 이미지로 합치거나 원본에 없는 임의 사진을 끼워 넣지 않습니다.

## 본문 블록

25개 디자인의 본문은 `showcaseInvitations.ts`의 각 `sections`에 읽는 순서대로 작성합니다. 카탈로그는 여기서 포함 블록을 표시하고 `buildShowcaseInvitation`은 같은 목록을 편집 가능한 게스트 블록으로 만듭니다. 날짜·시간·장소명은 각 디자인의 행사 정보에서 가져옵니다.

예를 들어 클래식 모먼트에는 신문 인터뷰와 식순, 선라이트 가든에는 정원 식탁과 우천 FAQ, 오렌지 스파크에는 워크숍 순서와 준비물이 들어갑니다. 핑크 케이크 클럽은 디저트 메뉴판으로, 리틀 파티 북은 첫해의 성장 수첩으로 시작합니다.

본문은 기존 네이티브 블록과 편집기에서 선택할 수 있는 기본·종이·라운드·테두리 카드 스타일로 구성합니다. `bulkData.sectionStyle`에 초대장 기본 스타일을 저장하고 새로 추가한 블록에도 적용합니다. 일괄 편집에서 기본 스타일을 바꾸고 상세 편집의 카드 디자인에서 `props.sectionStyle`로 개별 지정하거나 초대장 스타일을 다시 따를 수 있습니다. 공용 `InvitationChapter`가 편집기, 별도 미리보기, 템플릿 미리보기와 공개 화면에 같은 설정을 적용합니다. 구형 저장 데이터의 `props.collectionStyle`은 호환용으로 읽습니다. 새 템플릿은 공통 카드 설정을 사용합니다. 제목·본문 글꼴, 색상, 일정, 사진, 문구도 공용 빌더를 사용합니다. 템플릿 예시의 이름·일정·장소는 사용자가 변경할 수 있는 샘플입니다.

## 검증

관련 Jest는 25개 카드와 원본 파일 매핑, 썸네일과 JSON 존재 여부, 원본 Fabric 객체·텍스트 스타일·이미지 패턴 보존, ID 충돌 방지, 블록 지원과 게스트 파싱, 원본 로드 실패·재시도, 인증 후 선택 디자인 유지 여부를 확인합니다. 전체 빌드·타입 검사와 전체 Jest는 Frontend Gate에서 확인합니다.
